# QuizKit｜自訂題庫模擬考工具

> 匯入自己的題庫，自訂題數與時間，立即開始練習。無須安裝、無須註冊，也不需要自行寫程式。

QuizKit 是以 **HTML、CSS、JavaScript** 製作的輕量級模擬考框架。適用於證照考試、學校測驗、英文單字、自學複習等情境。使用者可將既有題庫整理成 CSV 或 JSON，匯入後直接建立模擬考。

## ✨ 主要功能

| 功能 | 說明 |
| --- | --- |
| 題庫匯入 | 支援 UTF-8 CSV、JSON；可管理多份題庫並個別匯出 |
| 題庫範本 | 網站內可下載 CSV、JSON 範例 |
| AI 轉換指令 | 以程式碼區塊呈現，可直接閱讀及一鍵複製 |
| 考試設定 | 選擇題庫、分類、題數（1–500）、時間（0–600 分鐘；0 為不限時） |
| 作答模式 | 模擬考、即時查看解答的練習模式、歷史錯題複習 |
| 隨機出題 | 隨機抽題，可選擇是否打亂選項 |
| 考試控制 | 上下題切換、題號導覽、暫停／繼續、時間到自動交卷 |
| 成績檢討 | 顯示成績、完整題目、所有選項、正確答案及來源提供的詳解 |
| 歷史紀錄 | 保留最近 50 筆考試紀錄，支援錯題重練 |
| 本機備份 | 可匯出及還原題庫與歷史紀錄的完整 JSON 備份 |

## 🚀 快速開始

1. 下載本專案，直接使用瀏覽器開啟 `index.html`；也可將網站部署到 Vercel。
2. 進入 **匯入題庫**，下載 CSV 或 JSON 範本，依格式準備題目。
3. 選擇題庫檔案、輸入題庫名稱，按下 **匯入檔案**。
4. 進入 **建立模擬考**，設定題數、考試時間、模式及分類。
5. 開始作答，交卷後查看成績與詳解；有需要可進行錯題重練。

> 題庫資料儲存在目前瀏覽器，不會因分享網址而自動分享給其他人。

## 📚 題庫格式

### CSV：適合 Excel / Google 試算表

使用 UTF-8 編碼，第一列為欄位名稱，每列一題。可以先編輯試算表，再匯出為 CSV。

```csv
id,question,optionA,optionB,optionC,optionD,optionE,optionF,answer,explanation,category,difficulty
Q001,1 + 1 等於多少？,1,2,3,4,,,B,1 + 1 = 2。,數學,簡單
Q002,下列哪些數字是偶數？,2,3,4,5,,,A|C,2 與 4 都是偶數。,數學,簡單
```

### JSON：適合 AI 產生及程式批次處理

```json
{
  "questions": [
    {
      "id": "Q001",
      "question": "1 + 1 等於多少？",
      "optionA": "1",
      "optionB": "2",
      "optionC": "3",
      "optionD": "4",
      "answer": "B",
      "explanation": "1 + 1 = 2。",
      "category": "數學",
      "difficulty": "簡單"
    }
  ]
}
```

JSON 也支援直接以題目陣列作為最外層；每題的選項亦可使用 `options: [{"id":"A","text":"..."}]` 結構。

### 欄位規格

| 欄位 | 必填 | 用途 |
| --- | --- | --- |
| `question` | 是 | 完整題目文字 |
| `optionA`, `optionB` | 是 | 至少兩個選項 |
| `optionC` ～ `optionF` | 否 | 其他選項 |
| `answer` | 是 | 正確選項字母，如 `B`；複選用 `A|C` |
| `explanation` | 否 | 詳解或解題說明 |
| `category` | 否 | 題目分類或章節 |
| `difficulty` | 否 | 難易程度 |
| `id` | 否 | 題目識別碼，建議每題不同 |

匯入時，每題答案必須指向實際存在的選項；缺少必要欄位或格式不正確可能導致匯入失敗。CSV 欄位若包含逗號或換行，請使用符合 CSV 規範的雙引號包覆。

## 🤖 使用 AI 快速整理題庫

QuizKit 的 **匯入題庫** 頁面提供「AI 題庫轉換指令」程式碼區塊，右上角可一鍵複製，貼到大型語言模型裡請它幫你把你自己的題庫彙整成需要的格式。

1. 開啟 QuizKit，進入 **匯入題庫**。
2. 在 AI 指令區塊點擊 **複製指令**。
3. 將指令連同原始題庫內容提供給 ChatGPT 或其他 AI。
4. 請 AI 產生符合 QuizKit 格式的 JSON，儲存為 `.json` 檔。
5. **人工核對題目、答案及詳解**，再匯入 QuizKit。

AI 指令會要求保留原題、檢查答案欄位，並避免猜測來源未提供的正確答案。尤其是法規、日期、金額與數字題，仍應以可靠原始資料核對。


## 💾 資料儲存、備份與還原

- 題庫、歷史紀錄及進行中的考試會儲存在瀏覽器 `localStorage`。
- 重新整理頁面後，可恢復已儲存的考試進度；主動暫停時倒數計時停止。
- 在 **歷史考試紀錄** 中，可使用 **備份全部資料（JSON）** 與 **還原備份**。
- 還原備份會覆蓋目前瀏覽器中的題庫與歷史成績，操作前請先備份。
- 清除網站資料、更換瀏覽器或裝置可能造成資料無法存取，請定期備份。

## ⚠️ 目前版本限制

- **純前端單機版**
- **不是正式監考系統**：瀏覽器端的計時、題目及答案無法提供防作弊保障。
- **容量限制**：單一匯入檔案上限為 8 MB，瀏覽器儲存空間有限；大型題庫建議分批匯入。
- **題型限制**：以文字型單選及複選題為主，尚未提供 PDF 直接辨識、圖片題、申論題或 AI 自動批改。
